# Gallery captions

One per image, in upload order. Each says what the image *proves*, not what it
shows — the gallery is often the only part of a submission a judge scrolls, so
the five together have to carry the argument on their own.

| Image | Caption |
|---|---|
| `1-chart-landed.png` | ChatGPT asked for this chart and got back zero bytes of data. It never saw a salary. |
| `2-refusal.png` | Asked for the highest salary in Engineering it refuses: a maximum is one person's exact pay. It offers a percentile instead. |
| `3-seal.png` | Once the data is loaded the page revokes its own network access, and the browser refuses all five ways out. |
| `4-verbatim.png` | The exact text the agent received: department medians and cohort sizes. Search it for a name and there is none. |
| `5-ledger.png` | 98.9 MB read into the tab, 2.2 KB released to the agent, zero raw rows. |

`../thumbnail.png` is the project thumbnail, not a gallery image, and takes no
caption.
